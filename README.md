## Estructura

- `app/` — layout, página única y secciones (hero, proyectos, habilidades, certificaciones, contacto).
- `components/` — header y footer.
- `lib/data.ts` — todo el contenido en un solo archivo; editarlo actualiza el sitio.
- `public/` — imágenes, logos, CV y PDFs de certificados.

## Contenido

Proyectos (web, móvil y full-stack), stack de habilidades, certificaciones con enlace a su PDF o credencial, y datos de contacto con CV descargable.

## Optimización

- App Router con páginas estáticas prerenderizadas.
- Fuentes autoalojadas con `next/font`.
- Tailwind 4 genera solo el CSS usado.

## Desarrollo

```bash
npm install
npm run dev
```
